The code base consists of four Python files, three Jupyter notebooks, two (including this) Markdown files, and the report as pdf.

## `main.py`
This files should be disregarded; I only used it for some testing and some crude calculations.


## `coefficient_analysis.py`
This file contains the code used to calculate the spread of the Fourier coefficients of each model.
It also contains functions to graph said spreads, either as a scatter plot on the complex plane for a subset of coefficients, or the standard deviation of the spread for all coefficients.
This file should be run directly.


## `quantum.py`
This file defines the quantum circuits that correspond to each model.
Since the observable and variational layers do not change, these are defined separately.
There is also a function that generates a random instance (i.e. generates random parameters) for a given parametrised circuit, so that the output can be used as target function.
This file should be imported.


## `random_functions.py`
This file contains functions that generate the random target functions.
This file should be imported.


## `testing.ipyng`
I conducted some preliminary tests in this notebook, which includes fitting single models to single targets.
The code here is what the code in the notebooks below are based on.


## `fitting.ipynb`
This notebook is where the main work is done.
It defines everything from the training loop to the models and target functions, and does the fitting and plotting.
The code in there is explained in markdown cells as well as comments


## `more_parameters.ipynb`
Another notebook that should handle fitting and plotting, but this time only of the Engineered spectrum model with extra trainable layers.
I split this off into another notebook because the plots would have looked different from those generated by the previous notebook.
No results of this notebook are found in the report; why is explained in the report.


## `planning and log.md`
I kept a somewhat detailed log of my work in this file, which includes (outdated) plans for this project and summaries of my thought processes.
